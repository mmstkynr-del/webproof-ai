# WebProof AI

AI destekli web takip ve doğrulama sistemi.

## Amaç

Kullanıcının verdiği web sitelerini veya web sayfalarını belirli aralıklarla kontrol etmek, değişiklikleri tespit etmek, AI ile analiz etmek ve gerektiğinde kullanıcıya bildirim göndermek.

## İlk mimari

- Cloudflare Workers
- AI Agent
- Web Crawler
- Scheduler
- Notification
- Database

İlk çalışan prototip.
